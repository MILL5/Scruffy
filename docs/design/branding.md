# MILL5 branding

Applied at the user's request on November 8, 2026.

- Official white logo: https://mill5.com/wp-content/uploads/2025/11/MILL5_Logo-1.png
- Reference site: https://mill5.com/
- Palette source: https://mill5.com/wp-content/uploads/corzo-style-custom.css
- Primary cyan: `#119BC5`
- Sidebar slate: `#222B30`
- Main charcoal: `#1B1B1B`
- Logo lettering: white

The official MILL5 wordmark appears only in About Scruffy, available from the sidebar or app menu. Scruffy's original broom mark appears beside its name, in the welcome view and as the app/Dock icon, using the same color family. The app explicitly loads the broom icon on launch; the bundle references `ScruffyBroom.icns` to avoid reusing the old icon filename.

Appearance offers System, Light and Dark, persisted locally across launches. System follows macOS. Surfaces, navigation, cards, borders, dialogs and controls use theme-aware cyan/slate colors; the light theme uses a deeper cyan for readable accent text. Chart colors use related blue and slate tints. No cleanup behavior changes are part of these branding updates.
