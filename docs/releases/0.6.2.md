## What's new in Scruffy 0.6.2

- **Closing the window no longer strands the app.** Closing Scruffy's window now quits it, so opening it again always shows the window. If a cleanup is still running, Scruffy stays open in the background to finish, and clicking its Dock icon or opening it again brings the window back.

## Requirements

A Mac with Apple silicon running macOS 26 or later.

## Install

Open `Scruffy.dmg` and drag Scruffy to Applications.
