## What's new in Scruffy 0.5.0

- **Undo a cleanup.** Each finished job has an Undo button that puts back the files still in Trash. Jobs with nothing left to restore can be removed from the list.
- **Search recovery history.** The same word search used in the file lists now narrows the recovery history.
- **Remove every copy of a duplicate.** Click a duplicate's checkbox again to add the next copy; Control-click selects them all. Scruffy warns before the original goes too.
- **Unfinished downloads are left alone.** `.crdownload`, `.part`, `.download` and `.partial` files are skipped.
- **Settings in the app menu.** Scan options and Appearance moved to Scruffy > Settings… (⌘,). Every scan option starts on.
- **Clearer sidebar.** Rows line up, the whole row is clickable, and switching category no longer shows the previous category's files.
- **Timing.** The scan reports how long it took, and each job's details show where the time went.
- **Purgeable space.** Free space is measured before and after a cleanup, and Scruffy reports the actual change.

## Install

Open `Scruffy.dmg` and drag Scruffy to Applications.
