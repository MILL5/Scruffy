## What's new in Scruffy 0.6.0

- **Faster scans.** Checking each file takes about a third of the time it did.
- **Much faster browser-cache cleanup.** Scruffy still stops the moment a browser opens, but no longer spends most of the cleanup checking for one.
- **Choose which copy to keep.** Right-click a duplicate and pick "Keep this copy instead of the original". Scruffy now protects a copy outside Downloads when there is one.
- **Your scan settings stick.** Chosen folders and scan options are remembered between launches.
- **See why a scan is waiting.** When macOS is asking for permission to open a folder, Scruffy says which folder it is waiting for. When macOS blocks a location, a button opens Full Disk Access settings.
- **More to go on in each row.** Rows show the modified date, text is larger, and each category opens with a one-line summary, leaving more room for files.
- **Restore without losing your place.** Restoring a file no longer clears the scan results.
- **Tidier recovery history.** Entries for files no longer in Trash are cleared when Scruffy opens.
- **Safer boundaries.** Other disks and disk images mounted inside your home folder, and cloud files that are not downloaded, are left out. Large files start at 500 MB as displayed.
- **Less reading during duplicate cleanup.** Each copy and its original are verified once, right before the move, instead of twice.

## Requirements

A Mac with Apple silicon running macOS 26 or later. Intel Macs and earlier macOS versions are no longer supported.

## Install

Open `Scruffy.dmg` and drag Scruffy to Applications.
