A cleanup app
should know its place.

Scruffy gives you a review, not a surprise. Scans are read-only, and ordinary file cleanup uses macOS Trash.

You choose every file.

No automatic selection or background cleaning. Files are checked again before a move. One original in every duplicate group stays put unless you explicitly select every copy, and Scruffy warns you first.

Some places are off limits.

Known cloud-sync folders, symlinks, hard links, app bundles, photo libraries, and sensitive system locations are excluded. Unusual sync tools and mount layouts still need your judgment.

Trash is yours to empty.

Scruffy never empties Trash. Moving files there does not release their space until you empty it yourself. Each cleanup can be undone, and a searchable recovery history restores single files without overwriting existing work.

Browser caches can wait.

Supported browsers must close before their caches can be cleaned. A normal quit request is offered only when you explicitly choose it.

System storage is a separate decision.

System purge and local Time Machine snapshot reclamation bypass Trash and require their own review. Snapshot reclamation also asks for administrator approval and permanently removes some local restore points.

Questions,
answered plainly.

What Scruffy does, what it leaves alone, and how to get a file back.

What is Scruffy?

Scruffy is a native Mac cleanup app for macOS 14 and later. It finds duplicate files, old downloads, large files, videos, browser caches, developer caches and temporary files, then lets you review each one before anything moves to Trash.

Does Scruffy delete files permanently?

No. Ordinary cleanup moves the files you choose to macOS Trash. Scruffy never empties Trash, so the space is released only when you empty it yourself. System purge and Time Machine snapshot reclamation are separate actions that bypass Trash and ask for their own confirmation.

Can I undo a cleanup?

Yes. Each cleanup job has an Undo button that puts back every file from that job that is still in Trash, without replacing existing files. You can also search the recovery history and restore single files. Files already emptied from Trash cannot be restored.

Does Scruffy upload my files or collect data?

No. Scans, search and video compression run on your Mac. Scruffy has no account, no analytics and no uploads.

How does Scruffy find duplicate files?

Scruffy compares file contents and confirms exact matches with SHA-256. It marks one file in each group as the original and keeps it unless you explicitly choose every copy.

Which files does Scruffy leave alone?

Known cloud-sync folders, symlinks, hard links, app bundles, photo libraries, sensitive system locations and unfinished downloads such as .crdownload and .part files are left out of scans.

Can I download Scruffy?

Not yet. Scruffy is in development and this page does not offer a public download. Follow progress at Inventing Fire with AI.
